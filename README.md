# Takt — 운영 시뮬레이션 랩

> 투자하기 전에, 시뮬레이션하라.

실제 기업의 생산 라인을 모델링하고 로봇·IoT·AI 투자안을 수천 번 반복 실험해, **현재 운영(표준) 대비** 이점과 문제점을 수치로 설명하는 산업공학 의사결정 도구입니다.

설치 없이 브라우저에서 실행되며, 시뮬레이션은 CPU 코어 수만큼의 Web Worker에서 병렬로 돌아갑니다. 서버·유료 API는 쓰지 않습니다.

## 주요 기능

| 화면 | 내용 |
|---|---|
| 케이스 | 산업별 교육용 가상 케이스 5개, 직접 입력, JSON 가져오기·내보내기 |
| 자유 시뮬레이션 | CSV 양식(엑셀 호환)에 실제 사례를 작성해 올리면, 검증한 뒤 표준과 모든 대안을 그대로 실행 |
| 라인 모델 | 1교대 실시간 애니메이션, 병목 표시, 공정별 시간 구성(가공·막힘·고장·대기) |
| 시뮬레이션 조건 | 반복 횟수, 난수 시드, 경제성, 로봇 리스크 가정, 자동화 프로필(업체 사양) |
| 로봇 영향 분석 | 가치 브리지(이론상 로봇 vs 실제 로봇), 리스크 토네이도(회수기간), 병목 이동, 이점·문제점 |
| 실험 | Monte Carlo(신뢰구간·P5–P95), 민감도 분석, 최적 투자 탐색(효율적 경계) |
| 보고서 | 컨설팅 1페이지 보고서(인쇄/PDF) |

## 모델

- 1초 단위 이산시간 흐름라인 모델이며, 버퍼가 유한하고 가공 후 다음 버퍼가 차 있으면 막힙니다(blocking-after-service).
- 사이클은 절단 정규분포(평균, CV), 고장·수리는 가동시간 기준 지수분포(MTBF/MTTR)를 따릅니다.
- 로봇 위험 요소로 순간정지, 체인지오버, 램프업, 정비 숙련도, SI 비용 초과, 안전 속도제한을 반영합니다.
- 시나리오 간 비교는 공통 난수(CRN)를 써서 공정하게 합니다.

자세한 설계와 디자인 규격은 [DESIGN.md](DESIGN.md)를 참고하세요.

## 로컬 실행

```bash
node serve.mjs
# http://localhost:8765
```

정적 파일만으로 동작하므로 GitHub Pages 같은 정적 호스팅에 그대로 배포할 수 있습니다.
